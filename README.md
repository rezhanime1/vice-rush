Vice Rush — a top-down 2D open-world GTA-style game built for the [make.fun gta6-01 bounty](https://make.fun/bounty/gta6-01).

Drive and walk around the open city of Solmar Bay, enter and exit cars, evade the police across a 0–5 star wanted system, and play through 5 story missions — all offline in a desktop browser, no libraries, no network.

Run it with `node serve.ts` (http://localhost:8080), or build with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
